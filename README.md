# Paradise Nursery - Proyecto Final Frontend

 Paradise Nursery es una aplicación web e-commerce para la venta de plantas de interior desarrollada con React y Redux Toolkit.

## Nombre del Proyecto
**Paradise Nursery Application**

## Características Principales
* **Página de Aterrizaje:** Presentación visual con imagen de fondo, descripción de la empresa y botón *Get Started*.
* **Listado de Productos:** 18 plantas divididas en 3 categorías únicas con miniaturas, nombres, precios e indicadores dinámicos de deshabilitación al añadir.
* **Carrito de Compra Dinámico:** Control de cantidades por artículo, cálculo global automático de costes/cantidades y navegación continua.
* **Accesibilidad:** Etiquetado semántico HTML5 y atributos `aria-label` optimizados para pasar las pruebas de WAVE sin errores críticos de accesibilidad.

## Instrucciones de Instalación
1. Clonar el repositorio.
2. Ejecutar `npm install`.
3. Ejecutar `npm start` para iniciar el servidor local de desarrollo.
